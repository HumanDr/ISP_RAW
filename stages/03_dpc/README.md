## 本节目标

- 理解 hot/dead pixel
- 知道同色邻居在 Bayer 上的位置
- 会调阈值避免误伤细节

## 输入 / 输出

|---|---|
| 输入 | f32 Bayer |
| 输出 | f32 Bayer，坏点被替换 |
| 目录 | `stages/03_dpc/` |

## 原理

坏点是制造缺陷：某个像素对光不敏感（dead）或暗电流特别大（hot）。它在图像上是一个孤立亮点/暗点。

Bayer 上同色邻居在上下左右各隔 2 像素。取 4 个同色邻居的中值 `med`；如果中心是这 5 个数里的极值，且 `|v-med| > threshold`，就用 `med` 替换。这个方法不能修大片 cluster 缺陷。

### 公式

```text
if (v <= min(n) or v >= max(n)) and |v - med| > T:
v = med
```

## 代码走读

文件：[`stages/03_dpc/stage.cpp`](stage.cpp)

1. 跳过最外 2 像素，避免越界。
2. 排序 4 个同色邻居，取中间两个的平均。
3. 阈值是归一化后的值，默认 0.05（约 750 DN）。

## 跑一跑

```bash
./build/isp_03_dpc out/02_lsc.isp out/03_dpc.isp --threshold 0.05
```

## 观察与实验

- 阈值 0.01/0.05/0.2，看修复像素数。
- 往 raw 里注入几个 0/65535，确认能修。
- 把阈值设成 0，观察正常细节被误伤。

## 常见坑

- 把非同色邻居拿来取中值，会引入彩色伪影。
- 阈值太小，把高频细节当坏点。
- 修完不检查边界，最外圈会出现黑边。

## 为什么放在这个位置

坏点在 RAW 域只是一个像素；去了马赛克，它会参与邻居插值，扩散成 3×3 的彩色斑块，再也回不去。
