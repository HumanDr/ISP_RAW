## 原理

RAW 噪声由光子噪声（与信号平方根相关）和读出噪声（与信号无关）组成，越暗越脏。

双边滤波同时看空间距离和像素值差：空间近、值也近的邻居权重大。只取 `dx+dy` 为偶数的同色邻居，避免把 R/G/B 混在一起。σ_range 可以用相邻同色像素差的中位数自动估计。

### 公式

```text
w = exp(-(dx²+dy²)/2σs²) · exp(-(I(p)-I(q))²/2σr²)
```

## 观察与实验

- `--sigma 0` 自动估计；手动 0.02 对比。
- 看暗部噪声和边缘细节的取舍。
- σ 太大，去马赛克后会出现“蜡像”皮肤。

## 常见坑

- 对全部邻居采样，把不同颜色混在一起。
- σ_range 设得比噪声大很多，边缘被糊掉。
- 先做 Gamma 再降噪，噪声模型不再线性。

## 为什么放在这个位置

RAW 域噪声是“单通道、线性”的，模型最简单；去马赛克后噪声会变成彩色斑块，再降噪就容易糊掉颜色边界。
