## 原理

镜头是有限口径的光学系统，边缘光线入射角大，照度按 cos⁴ 衰减；再加上微透镜和 CFA 的串扰，四角会明显变暗。

工业做法是用均匀白板拍 flat-field，直接得到每个像素的增益。本工程没有标定数据，只能按半径分桶，取每个 CFA 通道的亮度中位数，得到 `profile(r)`，再算 `gain(r)=profile(0)/profile(r)`。场景内容会污染估计，所以默认强度只给 0.7。

### 公式

```text
gain(r) = profile(0) / profile(r)
profile(r) = median(luma at radius r)
```

## 代码走读

文件：[`stages/02_lsc/stage.cpp`](stage.cpp)

1. 按 64 个半径桶累积直方图，求中位数。
2. 对 profile 做 5 点平滑，避免桶边界跳变。
3. 增益限幅到 [1, 2.5]，再做双线性插值。

## 观察与实验

- `--strength 0/0.5/1` 对比四角。
- 换一张四角有内容的图，估计会变差——解释“为什么需要 flat-field”。
- 把强度设 1，观察四角噪声是否被放大。

## 常见坑

- 用整幅图的全局均值做参考，会把场景亮度当成暗角。
- 增益不限幅，四角噪声会被过度放大。
- 在每个 CFA 通道分别估计后忘记平滑，会出现色块。

## 为什么放在这个位置

暗角是光学系统的乘性衰减，越靠后处理，越容易把噪声一起放大。放在 RAW 域、去马赛克之前，增益只作用在一次采样上。

## 自检

- 为什么四角增益大于 1？
- 没有 flat-field 时，场景内容会怎样污染估计？
- 强度 1 为什么会放大四角噪声？
