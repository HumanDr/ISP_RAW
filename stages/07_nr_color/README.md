## 本节目标

- 理解亮度/色度分离
- 知道为什么只降色度
- 会看彩色斑块

## 输入 / 输出

| | |
|---|---|
| 输入 | f32 RGB |
| 输出 | f32 RGB，色度噪声降低 |
| 目录 | `stages/07_nr_color/` |

## 原理

去马赛克会把 RAW 噪声变成彩色斑块。人眼对色度空间分辨率低，所以可以只降色度，保留亮度细节。

先把 RGB 转 YUV，对 U/V 做 3×3 中值，再按 `strength` 和原值混合，最后转回 RGB。中值能去掉孤立彩色噪点，但太强会让颜色边界渗色。

### 公式

```text
Y=0.2126R+0.7152G+0.0722B
U=(B-Y)/1.8556, V=(R-Y)/1.5748
```

## 代码走读

文件：[`stages/07_nr_color/stage.cpp`](stage.cpp)

1. 转 YUV 后分别存 Y/U/V。
2. 对 U/V 做 3×3 中值（排序 9 个数取中间）。
3. 按 strength 混合，再 YUV→RGB。

## 跑一跑

```bash
./build/isp_07_nr_color out/06_demosaic.isp out/07_nr_color.isp --strength 0.4
```

## 观察与实验

- 强度 0/0.5/1 对比彩色噪点。
- 看颜色边缘是否渗色。
- 对比只降 Y 的效果：细节会变糊。

## 常见坑

- 在 RGB 三通道各自中值，会把颜色边界弄脏。
- 强度 1，肤色会变成色块。
- YUV 转换公式和后面的 BT.709 不一致，颜色会偏。

## 为什么放在这个位置

去马赛克后噪声变成彩色斑块，但人眼对色度分辨率低，所以先在 RGB 域把色度压掉，避免后面 CCM 把色度噪声放大。
