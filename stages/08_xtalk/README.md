## 原理

CFA 的 R/G/B 滤光片不是理想窄带，红光会漏进 G/B，蓝光会漏进 G。结果就是颜色“发灰”、饱和度下降。

用 3×3 矩阵去掉非对角项：对角 1，非对角 `-k`，再按行归一化，保证白点不变。`k` 越大颜色越分离，也越容易过饱和。

### 公式

```text
R' = R - kG - kB
G' = -kR + G - kB
B' = -kR - kG + B
（每行除以行和）
```

## 代码走读

文件：[`stages/08_xtalk/stage.cpp`](stage.cpp)

1. 构造 `I - k(ones-I)`。
2. 每行除以行和，保证 (1,1,1)→(1,1,1)。
3. 逐像素矩阵乘，负值 clamp 到 0。

- 强度 0/0.05/0.1 对比肤色。

- 把 k 设 0.3，观察颜色崩坏。

## 常见坑

- 不做行归一化，整体亮度会变。
- 在 Gamma 后做串扰校正，线性关系不成立。
- k 太大，暗部负值被 clamp，颜色出现死区。

## 为什么放在这个位置

串扰是 CFA 光谱响应造成的，属于“相机色彩空间”的问题；必须在 CCM 之前校正，否则 CCM 会把串扰当成颜色偏差一起拟合。
